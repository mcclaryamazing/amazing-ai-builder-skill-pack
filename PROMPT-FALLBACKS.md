# Prompt Fallbacks

Use these when the skills are not installed, not detected, or you are using an AI coding tool that does not support skills yet.

Each prompt tells the coding agent what role to take, what to inspect, what not to do, and what final output to provide.

## Prompts

1. [Start a new AI tool project](prompts/01-start-a-new-ai-tool-project.md)
2. [Build my Shopify chatbot](prompts/02-build-my-shopify-chatbot.md)
3. [Connect my Shopify store](prompts/03-connect-my-shopify-store.md)
4. [Test my chatbot safety](prompts/04-test-my-chatbot-safety.md)
5. [Fix an error](prompts/05-fix-an-error.md)
6. [Review before launch](prompts/06-review-before-launch.md)

## Fallback Rule

If a prompt asks the agent to inspect files that do not exist in your project yet, tell it to create the closest beginner-friendly equivalent and explain the difference.
